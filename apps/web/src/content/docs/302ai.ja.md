## はじめに

[302.AI](https://302.ai/) は、豊富なモデルを選択できる従量課金制の AI リソースマーケットプレイスです。このガイドでは、API Key を取得し、OpenKoto で設定する方法を紹介します。

パフォーマンスとコストのバランスが最も優れた **Gemini 3 Pro** と **Gemini 3 Flash** の使用を強くお勧めします。

## ステップ 1：302.AI にアクセスする

[302.AI 公式サイト](https://302.ai/) にアクセスしてログインします。ホームページの「これより開始」をクリックします。

![302.AI ホーム](/docs/302ai/302-index.png)

## ステップ 2：API Key を作成する

API メニューで、「トークンを追加」または同様のボタンをクリックします。

![Key 追加ボタン](/docs/302ai/add-key-button.png)

ダイアログボックスで Key に名前を付け、必要に応じて制限額を設定します。

![Key 作成ダイアログ](/docs/302ai/add-key.png)

## ステップ 3：Key をコピーする

作成後、コピーボタンをクリックして API Key をクリップボードに保存します。

![Key をコピー](/docs/302ai/copy-key.png)

## ステップ 4：OpenKoto で設定する

OpenKoto を開き、**設定 > モデルプロバイダー** に移動して、**OpenAI 互換**（または 302.AI 専用オプションがある場合はそれを選択）を選択します。

1. **API Key**: 先ほどコピーした Key を貼り付けます。
2. **API Endpoint**: 302.AI の API エンドポイント（通常は `https://api.302.ai`）を入力します。
3. **モデルの絞り込み**: 下図のように、モデル名フィールドで必要なモデルを直接入力または選択できます。**gemini-3-flash** と **gemini-3-pro** を検索して使用することをお勧めします。

![OpenKoto での設定](/docs/302ai/openkoto-setting.png)

## 推奨モデル

以下のモデルの設定をお勧めします：

### Gemini 3 Pro
- **特徴**: 論理的思考能力が非常に高く、複雑な分析や高度な翻訳に適しています。
- **推奨シーン**: 精読、学術論文の解析、複雑な文法分析。

### Gemini 3 Flash
- **特徴**: レスポンスが非常に速く、軽量です。
- **推奨シーン**: スピーディーな翻訳、日常的な記事の閲覧、即時対話。
