## 简介

[302.AI](https://302.ai/) 是一个按需付费的 AI 资源超市，提供了丰富的模型选择。本指南将向您展示如何获取其 API Key 并在 OpenKoto 中进行配置。

我们强烈建议您选择 **Gemini 3 Pro** 和 **Gemini 3 Flash** 两个模型，以获得性价比最高的体验。

## 第 1 步：访问 302.AI

访问 [302.AI 官网](https://302.ai/) 并登录您的账号。在主页点击“以此开始”。

![302.AI 首页](/docs/302ai/302-index.png)

## 第 2 步：创建 API Key

在 API 菜单中，点击“添加令牌”或类似的按钮。

![添加 Key 按钮](/docs/302ai/add-key-button.png)

在弹出的对话框中，为您的 Key 命名，并设置相应的额度（如果需要）。

![创建 Key 对话框](/docs/302ai/add-key.png)

## 第 3 步：复制您的 Key

生成后，点击复制按钮将 API Key 保存到剪贴板。

![复制 Key](/docs/302ai/copy-key.png)

## 第 4 步：在 OpenKoto 中配置

打开 OpenKoto，进入 **设置 > 模型提供商**，选择 **OpenAI 兼容**（或 302.AI 专用选项，如果存在）。

1. **API Key**: 粘贴您刚才复制的 Key。
2. **API Endpoint**: 填写 302.AI 提供的接口地址（通常为 `https://api.302.ai`）。
3. **模型筛选**: 如下图所示，在模型名称处可以直接输入或筛选您需要的模型。我们推荐搜索并使用 **gemini-3-flash** 和 **gemini-3-pro**。

![在 OpenKoto 中配置](/docs/302ai/openkoto-setting.png)

## 模型推荐

我们建议您配置以下模型：

### Gemini 3 Pro
- **特点**：逻辑推理能力极强，适合复杂的分析与深度翻译。
- **适用场景**：精读、学术论文解析、复杂语法分析。

### Gemini 3 Flash
- **特点**：响应极快，非常轻量化。
- **适用场景**：快速翻译、日常文章阅读、即时对话。
