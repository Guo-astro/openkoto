## 简介

Google AI Studio 提供了免费使用强大的 Gemini 模型的机会。本指南将向您展示如何获取 API Key 并在 OpenKoto 中进行配置。

我们强烈建议您将 **Gemini 3 Pro** 和 **Gemini 3 Flash** 两个模型都添加到系统中，以获得最佳体验。

## 第 1 步：访问 Google AI Studio

访问 [Google AI Studio](https://aistudio.google.com/) 并使用您的 Google 账号登录。

![Google AI Studio 首页](/docs/aistudio/aistudio-home.png)

## 第 2 步：创建 API Key

点击左上角的 "Get API key" 按钮，或主视图中的 "Create API key"。

![创建 API Key 按钮](/docs/aistudio/create-key-button.png)

如果您还没有项目，请选择 "Create API key in new project"（在新项目中创建 API Key）。

![创建 Key 对话框](/docs/aistudio/creat-key.png)

## 第 3 步：复制您的 Key

生成后，复制您的 API Key。

![复制 Key](/docs/aistudio/cpoy-key.png)

## 第 4 步：在 OpenKoto 中配置

打开 OpenKoto，进入 **设置 > 模型提供商**，选择 **Google AI Studio**。粘贴您的 API Key。

![在 OpenKoto 中添加 Key](/docs/aistudio/add-key-in-openkoto.png)

## 模型推荐

我们强烈建议您在配置中同时添加这两个主要模型：

### Gemini 3 Pro
- **特点**：擅长处理复杂任务、深度推理和长上下文理解。
- **适用场景**：长篇章节精读、高难度学习任务、复杂问题解决。

### Gemini 3 Flash
- **特点**：速度极快，效率高。
- **适用场景**：大多数日常场景，如文章阅读、论文阅读、小说阅读、快速翻译。
