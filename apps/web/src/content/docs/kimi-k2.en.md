## Introduction

Kimi K2.5 is an advanced AI model developed by Moonshot AI. This guide will show you how to obtain an API key and configure it in OpenKoto.

## Step 1: Visit Moonshot Platform

Go to [Moonshot Platform](https://platform.moonshot.cn/) and click on the login button.

![Kimi Login Page](/docs/kimi/kimi-login-page.png)

## Step 2: Access the Console

After logging in, you will see the Moonshot developer platform homepage.

![Kimi Home](/docs/kimi/kimi-home.png)

## Step 3: Top Up Your Account

Before creating an API key, you need to add credits to your account. Navigate to the billing section and add funds.

![Kimi Pay](/docs/kimi/kimi-pay.png)

## Step 4: Create an API Key

Go to the API Keys section and click on "Create New Key" to generate your API key.

![Create New Key](/docs/kimi/kimi-newkey.png)

## Step 5: Copy Your Key

Once generated, copy the API key. Make sure to store it securely as it won't be shown again.

![Your Key](/docs/kimi/kimi-yourkey.png)

## Step 6: Configure in OpenKoto

Open OpenKoto, navigate to **Settings > Model Provider**, and select **Moonshot**. Paste your API key.

![Add Key in OpenKoto](/docs/kimi/input-to-openkoto.png)
