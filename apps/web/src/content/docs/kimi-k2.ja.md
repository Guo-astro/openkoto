## はじめに

Kimi K2.5 は、Moonshot AI が開発した先進的な AI モデルです。このガイドでは、API キーを取得し、OpenKoto で設定する方法を説明します。

## ステップ1：Moonshotプラットフォームにアクセス

[Moonshot Platform](https://platform.moonshot.cn/) にアクセスし、ログインボタンをクリックします。

![Kimi ログインページ](/docs/kimi/kimi-login-page.png)

## ステップ2：コンソールにアクセス

ログイン後、Moonshot 開発者プラットフォームのホームページが表示されます。

![Kimi ホーム](/docs/kimi/kimi-home.png)

## ステップ3：アカウントにチャージ

API キーを作成する前に、アカウントにクレジットを追加する必要があります。請求セクションに移動し、資金を追加します。

![Kimi 支払い](/docs/kimi/kimi-pay.png)

## ステップ4：APIキーを作成

API Keys セクションに移動し、「新しいキーを作成」をクリックして API キーを生成します。

![新しいキーを作成](/docs/kimi/kimi-newkey.png)

## ステップ5：キーをコピー

生成されたら、API キーをコピーします。キーは再度表示されないので、安全に保管してください。

![あなたのキー](/docs/kimi/kimi-yourkey.png)

## ステップ6：OpenKotoで設定

OpenKoto を開き、**設定 > モデルプロバイダー** に移動し、**Moonshot** を選択してAPI キーを貼り付けます。

![OpenKoto にキーを追加](/docs/kimi/input-to-openkoto.png)

## モデル推奨

### Kimi K2.5
- **最適な用途**：複雑な推論、コーディングタスク、マルチターン会話。
- **使用例**：コード生成、問題解決、文書分析、創作活動。
- **特徴**：128Kコンテキストウィンドウ、複雑な指示に従うことに優れています。
