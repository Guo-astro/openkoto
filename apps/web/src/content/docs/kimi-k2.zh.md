## 简介

Kimi K2.5 是由月之暗面（Moonshot AI）开发的先进 AI 模型。本指南将向您展示如何获取 API 密钥并在 OpenKoto 中配置。

## 第一步：访问开放平台

前往 [月之暗面开放平台](https://platform.moonshot.cn/) 并点击登录按钮。

![Kimi 登录页面](/docs/kimi/kimi-login-page.png)

## 第二步：进入控制台

登录后，您将看到月之暗面开发者平台主页。

![Kimi 主页](/docs/kimi/kimi-home.png)

## 第三步：账户充值

在创建 API 密钥之前，您需要为账户充值。导航到计费部分并添加资金。

![Kimi 充值](/docs/kimi/kimi-pay.png)

## 第四步：创建 API Key

进入 API Keys 部分，点击"新建 Key"来生成您的 API 密钥。

![创建新密钥](/docs/kimi/kimi-newkey.png)

## 第五步：复制您的密钥

生成后，复制 API 密钥。请确保安全存储，因为密钥不会再次显示。

![您的密钥](/docs/kimi/kimi-yourkey.png)

## 第六步：在 OpenKoto 中配置

打开 OpenKoto，导航到 **设置 > 模型服务商**，选择 **Moonshot**，粘贴您的 API 密钥。

![在 OpenKoto 中添加密钥](/docs/kimi/input-to-openkoto.png)

## 模型推荐

### Kimi K2.5
- **最适合**：复杂推理、编程任务和多轮对话。
- **使用场景**：代码生成、问题解决、文档分析和创意写作。
- **特性**：128K 上下文窗口，擅长遵循复杂指令。
