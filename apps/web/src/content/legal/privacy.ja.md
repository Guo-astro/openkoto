OpenKoto（以下「OpenKoto」「当方」）はオープンソースの言語学習ソフトウェアです。本ポリシーは、OpenKoto の各アプリ —— **iOS / iPadOS**（App Store）、**macOS・Windows・Linux** のデスクトップ版、openkoto.com の **Web アプリ**、**`koto` CLI / MCP サーバー** —— および任意の **OpenKoto クラウドサービス**（アカウント、同期、ホスト型 AI、メンバーシップ）における情報の取り扱いを説明します。

## 概要

- **アカウントは不要です。** サインインしない場合、コンテンツはお使いのデバイスにのみ保存され、当方は何も受け取りません。
- **サインインは任意です。** アカウントを作成すると、デバイス間で使えるよう、同期を選んだデータを当方が保存します。
- **自分の API キー（BYOK）：** ご自身の AI プロバイダーを設定した場合、テキストは**デバイスから直接**そのプロバイダーに送信され、当方のサーバーを経由しません。
- **広告なし**、**第三者の広告トラッカーなし**、**データの販売なし**、コンテンツを**モデルの学習に使用しません**。

## アカウントなしでの利用

ローカル機能はすべてアカウントなしで利用できます。以下のデータはデバイスにのみ保存され、ご自身で管理できます：

- インポートした記事、本、歌詞とその翻訳・解説
- 単語リスト、単語パック、間隔反復（FSRS）の復習履歴
- 読書進捗、しおり、学習統計
- アプリ設定、AI プロバイダー設定、API キー

保存場所：

- **iOS：** API キーは **iOS キーチェーン**に、その他のデータはアプリのサンドボックス内のローカルデータベースに保存されます。**共有拡張**を使う場合、共有したテキストはデバイス上のプライベートな App Group コンテナを通じてアプリに渡されます。
- **デスクトップ：** アプリのローカルデータフォルダに保存されます。
- **Web：** ブラウザの openkoto.com 用ローカルストレージ（IndexedDB）に保存されます。

ローカルデータは、アプリの削除（iOS）、アプリデータの消去（デスクトップ）、ブラウザのサイトデータの消去（Web）で削除できます。iOS ではキーチェーンの項目がアンインストール後も残る場合があります。API キーも削除したい場合は、アンインストール前に「設定」でモデル設定を削除してください。

## サインイン時に収集する情報

- **アカウント：** メールアドレス。Google・Apple・GitHub でサインインした場合は、それらが提供する名前とアバター。
- **同期データ：** 同期する単語、単語パック、復習履歴、記事、本（アップロードした元ファイルを含む）、歌詞、しおり、読書進捗。
- **デバイス：** デバイス名、プラットフォーム、アプリのバージョン。サインイン中のデバイス一覧に表示され、削除できます。
- **注文：** メンバーシップの状態、クレジット、決済チャネルの注文 ID または取引 ID。
- **ホスト型 AI：** OpenKoto のホスト型 AI を使った際のトークン数と消費クレジット。送信したテキストや AI の応答はログに保存しません。
- **セキュリティログ：** 不正利用の防止とサービス運用のための、IP アドレスやリクエスト時刻などの限定的な技術データ。

## 利用目的

同期、ホスト型 AI、メンバーシップ、サポートの提供と保護のためにのみ使用します。データの販売・貸与、広告への利用、コンテンツを AI モデルの学習に使用することはありません。

## AI 機能

**自分の API キー（BYOK）。** ご自身のプロバイダー（OpenAI、Google AI Studio、302.AI、Moonshot / Kimi、互換エンドポイントなど）を設定した場合、翻訳・解説するテキストはあなたのキーを使って**デバイスから直接**そのプロバイダーに送信されます。当方はプロンプト、応答、キーを受信・記録・保存しません。プロバイダーの利用には、そのプロバイダー自身の利用規約とプライバシーポリシーが適用されます。

**ホスト型 AI。** OpenKoto のホスト型 AI（有料プラン）を使う場合、リクエストは応答を生成する目的でのみ、当方のサーバーを経由して当方が利用するモデルプロバイダー（DeepSeek など）に送信されます。

## 支払い

- **Web：** 購入は販売者として **Creem** が処理します。当方が受け取るのは注文状況のみで、カード情報には触れません。
- **iOS：** アプリ内課金は **Apple** が処理します。当方はメンバーシップの有効化に必要な取引情報を受け取ります。Apple によるデータの取り扱いには [Apple のプライバシーポリシー](https://www.apple.com/legal/privacy/)が適用されます。

## 保存先とサービス提供者

クラウドデータは **Cloudflare**（Workers、D1、Durable Objects、R2）に保存されます。サービス運営に必要な範囲でのみ、以下の提供者とデータを共有します：Cloudflare（ホスティングとサインインメールの送信）、Creem と Apple（決済）、Google・Apple・GitHub（サインインに選んだ場合）、ホスト型 AI のモデルプロバイダー。

## その他のデバイス上の処理

- **Web からのインポート：** URL から記事をインポートする場合、ページはあなたのデバイス（Web アプリではブラウザ）から指定したサイトに直接取得されます。
- **読み上げ：** Apple プラットフォームの読み上げは Apple のデバイス上の音声合成を使用し、テキストは当方に送信されません。

## 保存期間とあなたの権利

**アカウント**ページから、同期データのエクスポート、サインイン中のデバイスの削除、アカウントの削除ができます。アカウント削除には **7 日間の猶予期間**があり、その後アカウント、同期データ、アップロードしたファイルは完全に削除されます。デバイス上のローカルデータは影響を受けないため、上記の方法で削除してください。データの開示・訂正・削除のご依頼は下記までご連絡ください。

## 児童のプライバシー

OpenKoto は一般向けの学習ツールであり、13 歳未満の児童を対象としていません。児童の個人情報を故意に収集することはありません。

本ポリシーは随時更新されることがあります。重要な変更は本ページと GitHub リポジトリで告知し、上記の日付を更新します。
