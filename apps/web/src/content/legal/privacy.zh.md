OpenKoto（“OpenKoto”“我们”）是一款开源的语言学习软件。本政策说明 OpenKoto 各客户端 —— **iOS / iPadOS**（App Store）、**macOS、Windows、Linux** 桌面端、openkoto.com **网页版**以及 **`koto` 命令行 / MCP 服务器** —— 和可选的 **OpenKoto 云服务**（账号、同步、托管 AI 与会员）如何处理你的信息。

## 摘要

- **无需账号。** 不登录时，你的内容只保存在你的设备上，我们不会收到任何数据。
- **登录是可选的。** 创建账号后，我们会保存你选择同步的数据，以便在多台设备间使用。
- **自带 Key：** 如果你配置了自己的 AI 服务，文本会**由你的设备直接发送**给该服务商，不经过我们的服务器。
- 我们**没有广告**，**不使用第三方广告追踪**，**不出售你的数据**，也**不会用你的内容训练模型**。

## 不登录使用 OpenKoto

不登录也能使用全部本地功能。以下数据只保存在你的设备上，由你掌控：

- 导入的文章、书籍、歌词及其翻译与讲解
- 生词本、词包以及间隔重复（FSRS）复习记录
- 阅读进度、书签与学习统计
- 应用设置、AI 服务配置与 API Key

保存位置：

- **iOS：** API Key 保存在 **iOS 钥匙串（Keychain）** 中；其他数据保存在应用沙盒内的本地数据库。使用**分享扩展**时，分享的文本通过设备上私有的 App Group 容器传递给应用。
- **桌面端：** 保存在应用的本地数据目录。
- **网页版：** 保存在浏览器为 openkoto.com 提供的本地存储（IndexedDB）中。

删除应用（iOS）、清除应用数据（桌面端）或在浏览器中清除网站数据（网页版）即可删除本地数据。在 iOS 上，钥匙串中的项目可能在卸载后仍然保留 —— 如需同时删除 API Key，请先在“设置”中移除模型配置再卸载。

## 登录后我们收集的信息

- **账号信息：** 邮箱地址；如果使用 Google、Apple 或 GitHub 登录，还包括其提供的名称与头像。
- **同步数据：** 你同步的生词、词包、复习记录、文章、书籍（含上传的原文件）、歌词、书签与阅读进度。
- **设备信息：** 设备名称、平台与应用版本，显示在“已登录设备”列表中，方便你移除。
- **订单信息：** 会员状态、积分以及支付渠道的订单号或交易号。
- **托管 AI：** 使用 OpenKoto 托管 AI 时的 token 数量与积分消耗。我们不会在日志中保存你发送的原文或 AI 的回复。
- **安全日志：** 有限的技术数据（如 IP 地址、请求时间），用于防止滥用和保障服务运行。

## 我们如何使用信息

仅用于提供和保护同步、托管 AI、会员与客服服务。我们不出售或出租你的数据，不用于广告，也不用你的内容训练 AI 模型。

## AI 功能

**自带 Key（BYOK）。** 当你配置自己的 AI 服务（如 OpenAI、Google AI Studio、302.AI、月之暗面 / Kimi 或任何兼容接口）时，你选择翻译或讲解的文本会使用你的 Key、**由你的设备直接发送**给该服务商。我们不会接收、记录或保存你的请求、回复或 Key。你对该服务商的使用受其自身服务条款和隐私政策约束。

**托管 AI。** 如果你使用 OpenKoto 托管 AI（付费套餐），请求会经由我们的服务器发送给我们使用的模型服务商（如 DeepSeek），仅用于生成回复。

## 支付

- **网页：** 购买由 **Creem** 处理（作为销售方）。我们只收到订单状态，不接触你的银行卡信息。
- **iOS：** 应用内购买由 **Apple** 处理。我们只收到开通会员所需的交易信息。Apple 对你数据的处理适用 [Apple 隐私政策](https://www.apple.com/legal/privacy/)。

## 存储与服务商

云端数据存储在 **Cloudflare**（Workers、D1、Durable Objects 与 R2）。我们仅在运行服务所必需的范围内与服务商共享数据：Cloudflare（托管与登录邮件发送）、Creem 与 Apple（支付）、Google / Apple / GitHub（如果你选择用它们登录），以及托管 AI 的模型服务商。

## 其他本地处理

- **从网页导入：** 通过 URL 导入文章时，页面由你的设备（网页版则由你的浏览器）直接从你指定的网站获取。
- **朗读：** Apple 平台上的朗读功能使用 Apple 的设备端语音合成，文本不会发送给我们。

## 数据保留与你的权利

你可以在**账户**页面导出同步数据、移除已登录设备或删除账号。删除账号后有 **7 天冷静期**，之后你的账号、同步数据和上传文件将被永久删除。设备上的本地数据不受影响，请按上文方式自行删除。你也可以联系我们查询、更正或删除你的数据。

## 儿童隐私

OpenKoto 是面向一般用户的学习工具，并非针对 13 岁以下儿童。我们不会故意收集儿童的个人信息。
