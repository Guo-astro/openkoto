openkoto.com used to be a marketing site. It is now the **OpenKoto web app** itself, and the docs, changelog and legal pages have moved into it.

### New on the web

- **Vocabulary review** with the FSRS spaced-repetition algorithm
- **Novel reading**: import EPUB and TXT books and read with AI translation
- **Lyrics**: import LRC lyrics, study line by line and sing along
- **AI assistant** that works with your own library

### Accounts and sync

- Sign in with email, Google, Apple or GitHub
- Words, reviews, books, lyrics and reading progress sync across web, iOS, macOS and Windows
- Optional [Plus and Pro plans](/pricing) for unlimited sync, hosted AI and the CLI

### For developers and agents

- `koto` CLI (`npm i -g @openkoto/cli`)
- Remote MCP server at `https://openkoto.com/mcp`
- An agent skill for Claude Code and other agents

### Moved pages

- `/privacy-policy` → [/privacy](/privacy), `/terms-of-service` → [/terms](/terms)
- Language-prefixed URLs such as `/zh/docs` now redirect to [/docs](/docs); the language follows your setting
- The privacy policy and terms now also cover accounts, sync and payments
