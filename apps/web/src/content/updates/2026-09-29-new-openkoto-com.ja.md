これまで紹介サイトだった openkoto.com が、**OpenKoto の Web アプリ**そのものになりました。ドキュメント、更新履歴、法的ページもこちらに移行しています。

### Web 版の新機能

- **単語復習**：FSRS 間隔反復アルゴリズム
- **小説リーディング**：EPUB・TXT をインポートし、AI 翻訳付きで読書
- **歌詞学習**：LRC 歌詞を一行ずつ学び、一緒に歌う
- **AI アシスタント**：あなたのライブラリと単語帳を使って学習をサポート

### アカウントと同期

- メール、Google、Apple、GitHub でサインイン
- 単語、復習記録、本、歌詞、読書進捗を Web・iOS・macOS・Windows 間で同期
- 無制限同期、ホスト型 AI、CLI が使える [Plus / Pro プラン](/pricing)（任意）

### 開発者とエージェント向け

- `koto` CLI（`npm i -g @openkoto/cli`）
- リモート MCP サーバー：`https://openkoto.com/mcp`
- Claude Code などのエージェント向けスキル

### ページの移動

- `/privacy-policy` → [/privacy](/privacy)、`/terms-of-service` → [/terms](/terms)
- `/ja/docs` などの言語付き URL は [/docs](/docs) にリダイレクトされ、言語は設定に従います
- プライバシーポリシーと利用規約に、アカウント・同期・支払いに関する内容を追加しました
